# Web Application Security Enhancement

This project focuses on enhancing web application security using Node.js and React. It includes measures to prevent common threats like SQL injection, XSS, and CSRF.

## Features
- **Helmet**: Adds security headers.
- **CSRF Protection**: Prevents cross-site request forgery.
- **XSS Protection**: Sanitizes user input to prevent XSS attacks.
- **OAuth 2.0**: Implements secure authentication.
- **Rate Limiting**: Prevents brute force attacks.

## How to Run

1. Install dependencies:
   - Backend: `cd server && npm install`
   - Frontend: `cd client && npm install`
2. Start the server: `node server/server.js`
3. Start the React app: `npm start` in the `client` folder.
